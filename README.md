# ⬛ Roblox Portable Updater
### Portable Roblox With Full Control & Cache / Shaders Saver  
**Powered by HK Projects**

---

## 📌 Overview
**Roblox Portable Updater** is a lightweight and smart updater designed to manage a **portable version of Roblox** without traditional installation.

It allows users to update Roblox safely while preserving important data such as **cache files** and **shader compilations**, resulting in faster startup times and smoother gameplay experience.

This project is ideal for:
- Portable setups
- Gaming cafés
- Restricted systems
- Multi-user environments
- Performance-focused users

---

## ✨ Features

✅ Portable Roblox (No installation required)  
✅ Automatic update system  
✅ Cache preservation system  
✅ Shader cache backup & restore  
✅ Faster game loading after updates  
✅ Clean and simple console interface  
✅ Lightweight & fast execution  
✅ Safe file replacement process  

---

## ⚙️ How It Works

1. Waits for Roblox to close safely.
2. Extracts new update files.
3. Preserves important cache & shader data.
4. Applies update automatically.
5. Restores performance-related files.

Result → Updated Roblox **without losing optimization data**.
